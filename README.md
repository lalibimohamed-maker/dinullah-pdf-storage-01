# dinullah-pdf-storage-01

Dedicated GitHub Release Storage for lawful PDF book assets used by Rechercher and موسوعة دينُ الله.

- Scope: public, redistributable PDF assets only
- Metadata: source, provenance, rights, verification, and SHA-256 remain tracked by the main system
- Research-only or rights-unclear material must not be published here
- Storage model: GitHub Release Assets, with SHA-256 deduplication and shard discovery
- Corpus policy: this repository does not write directly to the main Corpus
- Integrity: release payloads require provenance, rights, verification, and checksum metadata
